# Index and Evidence Ledger — Antigravity `/teamwork` Reverse-Engineering Set

This set records what was measured, and what could not be measured, about the `/teamwork-preview` subsystem of the Google Antigravity Linux CLI (shorthand: `/teamwork`): the artifact and build identity, the command's observable contract, the agent registry and the eight verbatim role descriptions recovered from it, the dispatch graph of its six routes, the coordination substrate and its two recovered struct schemas, the configuration gates and model tiers, the recovered sentinel prompt, the gap analysis against this repository, and the provenance and methodological limits that govern all of it. Documents `00`–`06` and `08` are static analysis of one extracted, stripped ELF binary — no part of the target was executed for them, and no network or authentication was used. `07` is the exception and is **PARTIAL**: the installed CLI (then byte-identical to the analysed 1.5.14 artifact) was executed in print mode; a live `/teamwork-preview` run was recognised and **dispatched** a `teamwork` subagent, but that subagent was refused twice by HTTP 429 quota and the sentinel completed the task inline. No `/teamwork-preview` **orchestrator turn** was observed in that attempt, so every teamwork workflow claim in `07` remains static; the later live runs (`12`, `13`, `15`) do record orchestrator turns and gates, and `16` records the interview gate's dispatch and a draft. `12`/`13` ran on **1.5.14**; `15`/`16` ran on **1.5.15** (then the live axis; now historical); the installed CLI is **1.5.16** from 2026-11-24, with no `/teamwork` run yet. `09` is a third kind of evidence: the shipped builtin text — sidecar JavaScript, plugin manifests and four skills — read directly and cited by `file:line`, with `assets/builtin/` preserving that tree byte-for-byte; it establishes the native-swarm board and its skills, and since 2026-11-22 it is corroborated by one **live swarm directory** (`09` §2.4, §3.5, §4). `10` adds a fourth: Google's public documentation page (`https://antigravity.google/docs/teamwork/`), re-fetched 2026-11-21 and cross-checked claim by claim against the binary. Docs establish intended behaviour, never implementation; `10` reports every disagreement rather than resolving it silently. `11` adds a fifth: the **state tree of the user's own completed prior runs**, read on disk under the CLI's app-data directory — the artifact root, ten document kinds, the folder-naming convention and a redacted gate template, with all project content withheld — plus a **second live invocation** that produced a lean native swarm instead of a teamwork dispatch (`11` §1.6–§1.7). It is evidence of what a completed run *writes*, not of the route or gate that produced it. The set is written for a reader who needs to know, claim by claim, exactly which byte offset, symbol, or repository file earns each statement, and which statements are `UNKNOWN` rather than merely unwritten.
