# Index and Evidence Ledger — Antigravity `/teamwork` Reverse-Engineering Set

This set records what was measured, and what could not be measured, about the `/teamwork-preview` subsystem of the Google Antigravity Linux CLI (shorthand: `/teamwork`): the artifact and build identity, the command's observable contract, the agent registry and the eight verbatim role descriptions recovered from it, the dispatch graph of its six routes, the coordination substrate and its two recovered struct schemas, the configuration gates and model tiers, the recovered sentinel prompt, the gap analysis against this repository, and the provenance and methodological limits that govern all of it. Everything in the set is static analysis of one extracted, stripped ELF binary — no part of the target was executed, no network or authentication was used, and no live run was observed. The set is written for a reader who needs to know, claim by claim, exactly which byte offset, symbol, or repository file earns each statement, and which statements are `UNKNOWN` rather than merely unwritten.

Prompt text governs an agent's instructions; no code path was found that validates compliance with the routing, recording or completion rules. `07-runtime-observed.md` is **NOT PERFORMED**, not pending: no Google authentication was available and no execution was attempted, so the set contains no runtime observation at all.

Together they produced the 49 decoded entries in `02`. The earlier statement that `docs/re/tools/` did not exist, and that the `pclntab` task was blocked by `SCOPE_BINDING_PERSISTENCE_FAILED`, is withdrawn.
- **Prompt recovery is limited to byte-contiguous literals.** Boundaries at fused literals are chosen and stated, not recovered: the sentinel slice starts at a marker inside `...a PROJECT SENTINEL.` and ends at the last newline of the Workflow Protocol list; the command description runs straight into `Show pinned hierarchy panels for a symbol.`; the `Post %d/%d (seq #%d by %s` format has no byte-adjacent `)` (re-verified with `xxd`: exactly 25 bytes, next byte `a`).
